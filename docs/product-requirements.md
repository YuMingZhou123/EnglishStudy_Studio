# 英语学习平台产品需求文档

版本：v0.1  
日期：2026-05-27  
状态：初稿，待讨论完善

## 1. 产品概述

本产品是一个面向英语学习者的三端学习平台，核心目标是通过 AI 对话、语境听写、词汇复习和个性化学习路径，帮助用户在真实语境中提升听、说、读、写和词汇应用能力。

第一阶段建议聚焦“大学生与职场初中级英语学习者”，优先解决两个高频痛点：

- 背单词脱离真实语境，记得慢、忘得快、不会用。
- 缺少口语和听力练习环境，无法高频输入与输出。

## 2. 产品定位

### 2.1 一句话定位

面向大学生和职场人的 AI 英语口语与语境记忆训练平台。

### 2.2 核心价值

- 用真实句子和语音帮助用户在语境中记单词。
- 用 AI 对话提供低压力、高频率的英语口语练习。
- 用分级训练降低学习门槛，并根据表现逐步提升难度。
- 用学习数据和错词复习形成持续反馈闭环。

### 2.3 目标用户

第一阶段建议优先覆盖：

- 大学生：四六级、考研英语、雅思托福预备、日常口语提升。
- 职场新人：面试、会议、邮件、汇报、商务沟通。
- 初中级自学者：希望通过碎片化训练提升听力、词汇和表达。

## 4. 核心功能

## 4.1 语境听写

语境听写是本产品的核心特色功能。系统播放一句英文语音，同时展示对应英文句子，但根据难度隐藏部分或全部内容，用户需要根据听到的语音输入答案。

### 4.1.1 功能目标

- 让用户通过“声音 + 拼写 + 句子 + 语义 + 场景”记忆单词。
- 帮助用户建立单词与真实表达之间的连接。
- 同时训练听力辨音、单词拼写、短语搭配和整句理解。

### 4.1.2 难度分级

#### 初级：核心关键词留空

适合新词学习和低压力练习。每句话隐藏 1 个核心词。

示例：

```text
音频：I usually have breakfast at seven.

I usually have ______ at seven.

答案：breakfast
```

训练重点：

- 单词识别
- 单词拼写
- 基础句意理解

#### 中级：多个关键词留空

适合词汇、短语和搭配训练。每句话隐藏 2 到 4 个关键词或短语。

示例：

```text
音频：Could you send me the report before Friday?

Could you ______ me the ______ before Friday?

答案：send / report
```

训练重点：

- 多词辨音
- 常用搭配
- 句子结构理解
- 场景表达

#### 高级：整句听写

适合听力强化和完整输出训练。页面不展示句子正文，用户需要输入完整句子。

示例：

```text
音频：We need to reschedule the meeting because of the weather.

________________________________________

答案：We need to reschedule the meeting because of the weather.
```

训练重点：

- 完整句子听写
- 语序
- 语法结构
- 听力细节
- 拼写准确度

### 4.1.3 练习流程

1. 用户选择学习目标、难度或系统推荐任务。
2. 系统播放英文语音。
3. 页面展示填空句或整句输入框。
4. 用户输入答案并提交。
5. 系统即时判断正确性。
6. 系统展示完整句子、中文释义、关键词解释、常见搭配。
7. 错误单词自动进入错词本和复习队列。

### 4.1.4 辅助能力

- 原速播放
- 慢速播放
- 重复播放
- 单词首字母提示
- 中文释义提示
- 查看答案
- 加入生词本
- 收藏句子
- 跟读本句

### 4.1.5 评分规则

初级：

- 判断目标词是否正确。
- 忽略大小写。
- 可配置是否忽略标点。
- 支持英美拼写兼容，例如 color / colour。

中级：

- 每个空独立评分。
- 短语整体评分。
- 展示每个空的正确、错误或部分正确状态。
- 错误项进入复习队列。

高级：

- 根据完整句子进行相似度评分。
- 检查漏词、多词、拼写错误和语序错误。
- 标点可作为弱校验，不作为主要扣分项。
- 给出整体分数和逐词反馈。

### 4.1.6 自适应难度

系统根据用户近期表现自动调整难度：

- 初级连续正确率高于 85%，推荐进入中级。
- 中级连续正确率高于 80%，推荐进入高级。
- 高级正确率低于 60%，推荐回到中级巩固。
- 某类词汇错误频繁时，自动增加相关复习句子。

## 4.2 AI 口语陪练

用户可以选择不同场景，与 AI 进行英语语音对话。

典型场景：

- 自我介绍
- 面试问答
- 会议沟通
- 旅行问路
- 餐厅点餐
- 商务邮件前置口语表达
- 校园讨论

核心能力：

- 语音输入
- AI 英语回复
- 对话纠错
- 更自然表达建议
- 场景词汇推荐
- 对话复盘报告

## 4.3 发音与流利度评测

用户朗读单词、短语或句子，系统给出反馈。

评分维度：

- 发音准确度
- 流利度
- 语速
- 停顿
- 重音
- 连读
- 语调

输出内容：

- 总分
- 问题单词
- 改进建议
- 标准音频对比
- 再练一次

## 4.4 单词与短语复习

用户在语境听写和 AI 口语中遇到的错词、生词、重点词会进入个人词库。

核心功能：

- 生词本
- 错词本
- 间隔重复复习
- 按场景复习
- 按考试词库复习
- 词汇掌握度标记

## 4.5 个性化学习路径

用户完成入门测试后，系统生成每日学习计划。

示例任务：

- 语境听写 10 句
- AI 口语对话 5 分钟
- 生词复习 15 个
- 跟读训练 5 句

推荐依据：

- 用户目标
- 当前等级
- 历史正确率
- 高频错词
- 连续学习天数

## 4.6 学习数据看板

展示用户学习进度和能力变化。

核心指标：

- 连续学习天数
- 今日学习时长
- 语境听写正确率
- 掌握词汇量
- 错词数量
- 口语练习时长
- 发音平均分
- 听写能力趋势

## 8. 技术建议

### 8.1 前端

- PC Web：React / Next.js
- 移动端：Flutter 或 React Native
- 微信小程序：Taro 或 uni-app

如果希望快速覆盖三端，可以优先考虑 Taro 或 uni-app；如果更重视长期体验和复杂交互，可以 Web + App + 小程序分别优化。

### 8.2 后端

- Node.js / NestJS 或 Java / Spring Boot
- PostgreSQL 存储业务数据
- Redis 存储缓存、验证码、学习状态
- 对象存储保存音频资源
- CDN 加速音频和静态资源

### 8.3 AI 与语音能力

需要接入或自研的能力：

- ASR：语音识别
- TTS：文本转语音
- LLM：AI 对话、解释、纠错、生成例句
- Pronunciation Assessment：发音评测
- Sentence Similarity：整句听写相似度判断

# 第一版内测招募与访谈话术

版本：v0.1
日期：2026-05-28
用途：用于招募 5 到 10 名真实用户，并按统一流程完成第一版语境听写内测。

## 1. 招募目标

第一轮内测不是为了获得夸奖，而是验证用户能否独立完成核心学习闭环：

```text
注册/登录 -> 学习首页 -> 三档听写 -> 提交反馈 -> 错词本 -> 错词复习 -> 学习记录
```

建议先找 5 到 10 人：

- 2 到 3 名大学生。
- 2 到 3 名职场新人。
- 1 到 2 名通用初中级英语学习者。
- 尽量覆盖初级、中级和基础较好的人。

## 2. 筛选条件

优先邀请：

- 最近 3 个月有英语学习需求的人。
- 愿意花 15 到 25 分钟试用并说真实感受的人。
- 平时会背单词、听英语、准备考试、面试或职场英语的人。
- 能接受产品还在早期、可能有小问题的人。

暂时不优先邀请：

- 专业英语教师。
- 只关心机构端、班级管理或课程售卖的人。
- 对英语学习没有真实需求的人。

## 3. 招募消息模板

微信或私聊可直接发送：

```text
我最近在做一个英语学习小工具，核心是“听一句真实英语句子，然后根据难度填关键词或整句听写”，想验证它对语境记单词有没有帮助。

现在第一版已经可以本地试用了，我想找 5 到 10 个真实用户做一次 15 到 25 分钟的小内测。

你不需要准备什么，只要按我给的任务试一下，然后告诉我哪里看不懂、哪里卡住、愿不愿意继续做下一题。

如果方便的话，这两天能不能约一个时间？我更想听真实反馈，不用客气。
```

朋友圈或群里可发送：

```text
我在做一个英语学习产品第一版，方向是“语境听写 + 关键词填空 + 错词复习”，想找 5 到 10 位有英语学习需求的朋友帮忙内测。

耗时 15 到 25 分钟，不需要英语很好，初级/中级都可以。重点是看你能不能独立完成、能不能理解三种难度、觉得这种方式对记单词有没有帮助。

愿意帮我试一下的朋友可以私信我，我会约一个具体时间。反馈越真实越好。
```

## 4. 预约确认模板

```text
谢谢你愿意帮我内测。

时间：____
预计耗时：15 到 25 分钟
方式：我发你测试地址/当面演示，你按任务操作，我只观察并记录问题

这不是考试，也不是测你的英语水平。产品还在第一版，所以你遇到卡顿、看不懂、听不清、想吐槽的地方都很有价值。
```

## 5. 内测开始前说明

开始前照着说：

```text
这个产品还在第一版，我主要想验证一个核心问题：听一句英语，再填关键词或整句听写，是否能帮助你在语境里记单词。

接下来请你尽量自己操作。我不会马上告诉你怎么点，因为我想观察真实用户会不会卡住。

你可以边操作边说出你的想法，比如“我不知道这里要填什么”“这个按钮我没看懂”“这个音频太快了”。这些都很重要。

如果确实卡住超过 30 秒，我再给你提示。
```

## 6. 观察者记录规则

记录时尽量写事实，不要只写判断。

推荐写法：

```text
U03 在高级听写页停留 45 秒，不确定是否要输入整句。
U05 找不到错词本入口，先点了学习记录。
U02 说慢速播放还是有点快。
U01 完成中级后主动点击下一题。
```

避免只写：

```text
用户觉得不好用。
用户不懂。
页面有问题。
```

## 7. 任务提示卡

如果用户问“我要做什么”，只给任务，不解释具体按钮位置：

```text
请你完成下面几件事：

1. 注册或登录。
2. 设置你的英语水平和学习目标。
3. 进入学习首页。
4. 完成初级听写 2 题。
5. 完成中级听写 2 题。
6. 完成高级听写 1 题。
7. 试一次原速播放和慢速播放。
8. 试一次首字母提示和中文提示。
9. 故意答错 1 题，看反馈是否能看懂。
10. 打开词汇本，找到错词并复习 1 题。
11. 打开学习记录，看是否能理解统计和明细。
```

## 8. 访谈问题

完成任务后问：

1. 你觉得这个练习方式在帮你记单词吗？为什么？
2. 初级、中级、高级三种难度你能理解区别吗？
3. 哪一步最卡？
4. 哪个页面或按钮你最没把握？
5. 音频听起来清楚吗？原速和慢速有区别吗？
6. 反馈结果看得懂吗？你知道自己错在哪里吗？
7. 错词本和复习入口自然吗？
8. 如果明天再打开，你愿意继续做下一题吗？为什么？
9. 如果它变成正式产品，你觉得什么能力最值得保留？
10. 你最希望下一版先改什么？

## 9. 反馈表填写建议

每位用户结束后，立刻在 `feedback/internal-beta-feedback.html` 记录一行：

| 字段 | 推荐填写 |
| --- | --- |
| `UserType` | `university_student`、`workplace_newcomer`、`general_learner` |
| `EnglishLevel` | `beginner`、`intermediate`、`advanced`、`uncertain` |
| `CompletedTest` | 完成核心任务填 `yes`，否则填 `no` |
| `IndependentCompletion` | 基本不靠提示完成填 `yes` |
| `StuckStep` | 写任务编号和卡点 |
| `UnderstandsDifficulty` | `yes`、`partial`、`no` |
| `WillingNext` | `yes`、`average`、`no` |
| `PerceivedUseful` | `yes`、`partial`、`no` |
| `AudioIssue` | `none`、`too_fast`、`mechanical`、`low_volume`、`playback_failed` |
| `Priority` | 阻断为 `P0`，明显影响体验为 `P1`，优化建议为 `P2` |
| `Notes` | 写用户原话和观察事实 |

## 10. 内测后命令

每轮记录后，导出 CSV 并先预校验：

```powershell
.\scripts\import-acceptance-csv.ps1 -Kind beta -ValidateOnly
```

确认 `valid: true` 后再导入并刷新看板：

```powershell
.\scripts\import-acceptance-csv.ps1 -Kind beta -RefreshArtifacts
.\scripts\prepare-mvp-acceptance.ps1 -SkipReadiness
```

第一轮全部完成后再跑：

```powershell
.\scripts\check-mvp-readiness.ps1 -IncludeBuild
```

## 11. 通过标准

第一轮内测最低通过标准：

- 至少 5 名用户完成测试。
- 至少 4 名用户能独立完成核心流程。
- 至少 4 名用户能理解三种难度。
- 至少 3 名用户愿意继续做下一题。
- P0 问题为 0。

如果未达标，不急着加新功能，先修阻断点和高频卡点。
